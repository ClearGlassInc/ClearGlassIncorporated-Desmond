# AGENTS.md

This repository's engineering, security, and automation charter for **all** AI
coding agents lives in **[`CLAUDE.md`](./CLAUDE.md)** — a single source of
truth to avoid drift.

Read `CLAUDE.md` before making changes. In short: secure-by-design,
automation-first, smallest-correct-change, validate before push, no secrets in
the repo, least-privilege workflows, and no PRs unless explicitly requested.
