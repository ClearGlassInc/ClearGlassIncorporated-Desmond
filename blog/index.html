SEO blueprint

Fast static publishing with machine-readable authority.

GitHub Pages and Jekyll can support the full hub through Markdown posts, front matter, reusable includes, static JSON indexes, and lightweight client-side filtering.

  1. Metadata

    Use unique titles, descriptions, canonical URLs, Open Graph, Twitter cards, and `jekyll-seo-tag` for every post.

  2. Schema

    Emit `Blog`, `BlogPosting`, `BreadcrumbList`, `Organization`, `FAQPage`, and `ItemList` JSON-LD where relevant.

  3. Internal links

    Every article links to a pillar, a series page, two related posts, and one conversion path.

  4. Topic clusters

    Organize posts around governed AI, agents, cyber, OSINT, automation, financial crime, and high-trust systems.

  5. Share surfaces

    Add quotable pull quotes, social preview copy, copy-link actions, and section anchors for citation.

  6. Performance

    Static HTML/CSS, no heavy frameworks, font preconnects, compressed images, and progressive enhancement only.
