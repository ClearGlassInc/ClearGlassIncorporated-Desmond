Implementation Notes

Customize fast without breaking the system

Colors

Override --cg-accent, --cg-accent-2, and --cg-accent-3 on any button variant for cyan, blue, violet, green, or red command states.

Speed

Adjust --cg-speed, --cg-pulse-speed, and --cg-sweep-speed globally in :root to tune motion from quiet enterprise to high-energy operator mode.

Usage

Add class="cg-btn cg-btn--primary" to links or buttons. Use cg-btn--command for high-priority control actions.
