# Burlington Campaign Playbook

Initial campaign packages live in `data/campaigns/initial_burlington_campaigns.json`.

## Local SEO structure

- `/burlington-cybersecurity-services/`
- `/burlington-microsoft-365-security-review/`
- `/burlington-ransomware-readiness/`
- `/halton-nonprofit-cyber-resilience/`
- `/ontario-ai-governance-readiness/`

Use Organization, LocalBusiness, ProfessionalService, Service, FAQPage, Article, and BreadcrumbList schema. Do not create doorway-page variants; every location page must add local proof, service specificity, and useful executive guidance.

## Measurement

Prioritize qualified leads, booked consultations, proposals, won revenue, recurring revenue, CAC, conversion rate, sales-cycle duration, and content-assisted conversions.
