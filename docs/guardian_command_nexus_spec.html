Entity Types

Person, Organization, Account, Device, IP, Location, Vessel, Transaction, Communication, Case, Incident, Mission, Artifact, Alert, PolicyDecision, ModelVersion, PromptVersion.

Relationship Types

OWNS, USES, TRANSACTS_WITH, LOCATED_AT, ASSOCIATED_WITH, MENTIONED_IN, TRIGGERED, INVESTIGATED_IN, LINKED_TO_CASE.

Mandatory Metadata

confidence_score, source_system, lineage_ref, classification_label, compartment_tags, valid_time, system_time, provenance_hash.

Permission model uses ABAC + ReBAC + mission context (deny-by-default), and ontology slices constrain AI prompt context to policy-approved data only.

3) AI and Agent Design

Commander Copilot

Workflow

Event → Triage → Enrichment → Correlation → Risk Scoring → Recommendation → Human Approval Gate → Action Execution → Outcome Capture.

4) Self-Improvement Loop (Safe + Audited)

  1. Capture signals: operator edits, ratings, alert outcomes, mission success, latency/cost, human override frequency.
  2. Generate eval datasets and benchmark prompt/model/workflow candidates.
  3. Run policy checks to prevent forbidden behavior expansion.
  4. Require governance approval for prompt/workflow/router changes (Gate C).
  5. Apollo canary rollout (ring1), drift monitoring, and automatic rollback on regression thresholds.

Immutable IDs: prompt_version, workflow_version, router_policy_version, model_snapshot.

5) Full-Stack Implementation

Frontend

Next.js + TypeScript + SSE/WebSockets. Routes: /missions/:id, /cases/:id, /approvals, /copilot, /evals.

Gateway + BFF

OIDC/JWT, request scoping headers, policy pre-check, response redaction by classification.

Services

FastAPI microservices for ingest, entity resolution, threat scoring, case orchestration, agent runtime, policy, eval, and feedback learning.

Eventing + Data

Kafka/Pulsar topics, Foundry Bronze/Silver/Gold, OpenSearch + vector retrieval, ontology sync to Gotham.

6) Security and Governance

  • Zero trust enforcement on every request (mTLS + short-lived credentials + OPA/Rego PDP).
  • Fine-grained row/column/entity/edge-level policy enforcement with coalition boundary controls.
  • Immutable provenance via append-only audit logs, signed artifacts, and end-to-end correlation IDs.
  • AI governance for prompt/model/workflow change control with board approval and rollback safety.
