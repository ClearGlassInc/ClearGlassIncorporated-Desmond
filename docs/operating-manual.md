# Operating Manual

1. Review market brief and replace verification markers with source URLs.
2. Import only lawful, authorized lead records.
3. Run duplicate and suppression validation.
4. Draft campaign assets and attach evidence for factual claims.
5. Run compliance validation and attribution checks.
6. Submit approval package for any external action.
7. Export approved assets to channels manually or through approved integrations.
8. Import actual performance metrics; never fabricate results.
9. Generate optimization recommendations.
10. Require human approval before changes to budgets, targeting, publishing, outreach, or data collection.
