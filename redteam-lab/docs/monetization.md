# Monetization Strategy — ClearGlass Detection Forge

## Executive Summary

The repository is the **lead engine**, not the product. The commercial opportunity
is in managed assessments, enterprise retainers, detection engineering consulting,
and compliance evidence automation. The open-source core builds trust, drives
inbound, and demonstrates capability — the paid tiers convert that trust into revenue.

---

## Revenue Model

### Tier 1: Open Source (Free)
**Purpose:** Top-of-funnel lead generation, brand building, talent signaling

- Full scenario YAML library on GitHub
- ATT&CK Navigator layer templates
- Sigma rule library
- PDF report templates (Jinja2)
- Community support (GitHub Issues)

**Revenue:** $0 direct · High indirect value (inbound assessment inquiries)

---

### Tier 2: Professional Assessment ($6,000–$12,000/engagement)
**Purpose:** Primary revenue driver · 3–5 engagements/month at scale

**Deliverables:**
- ClearGlass analyst-led 5-day purple team engagement
- Custom scenario selection from full library
- Managed lab provisioning (no setup burden on client)
- Executive Summary + Technical Report + Compliance Pack
- Detection rule delivery (Sigma, Splunk SPL, Sentinel KQL)
- 30-day remediation support window
- Re-test validation included

**Target buyers:**
- Mid-market companies ($100M–$1B revenue) with a SOC
- Fintech and banking security teams under regulatory pressure
- Companies preparing for SOC 2 Type II or PCI DSS 4.0 assessments
- Companies that just hired a new CISO and need a baseline

**Pricing rationale:**
- Big 4 and Big Law equivalent engagement: $40,000–$120,000
- Boutique red team firms: $15,000–$50,000
- ClearGlass (productized, efficient): $6,000–$12,000
- Differentiation: structured output, compliance automation, detection rules included

---

### Tier 3: Enterprise Retainer ($18,000–$30,000/year)
**Purpose:** Predictable recurring revenue · Target 10 accounts = $200K ARR

**Deliverables:**
- Monthly purple team exercises (2 days/month)
- Continuous detection monitoring (quarterly gap analysis)
- Analyst training program (4 sessions/year)
- Dedicated ClearGlass analyst assigned
- Board-ready quarterly security posture reports
- Compliance evidence automation for annual audits
- Priority scheduling and same-week emergency assessments

**Target buyers:**
- Companies with $1B+ revenue and established security programs
- Financial institutions with OSFI/OCC/FDIC regulatory obligations
- Healthcare organizations with HIPAA security rule obligations
- Critical infrastructure operators

---

### Tier 4: Platform Licensing ($500–$2,000/month)
**Purpose:** Scalable, low-touch revenue · Target MSPs and large in-house teams

**Model:** License the clearforge CLI and scenario library for internal use

**Deliverables:**
- Full CLI access with all scenarios
- Private scenario library updates (monthly)
- SIEM integration modules
- Report generation engine
- Technical support (Slack/email, 24-hour SLA)

**Target buyers:**
- MSSPs building detection validation into their service offering
- Large enterprises (5,000+ employees) with in-house red teams
- Security consulting firms adding structured adversary simulation

## Go-to-Market Strategy

### Phase 1: Repository Launch (Month 1–2)
- Publish GitHub repository with full documentation
- Post 3 technical articles on LinkedIn/Medium demonstrating gaps found
- Submit to r/netsec, Hacker News, security mailing lists
- Create ATT&CK Navigator layer showing coverage

**Goal:** 200+ GitHub stars, 50+ qualified inbound inquiries

### Phase 2: First Paying Clients (Month 2–4)
- Target: 3 Professional Assessment engagements at $8K each = $24K
- Outreach to 50 CISOs in banking, fintech, and healthcare sectors
- Offer free 1-hour "detection gap briefing" to qualified prospects
- Use engagement results (anonymized) as case studies

**Goal:** $24K revenue, 3 case studies, testimonials

### Phase 3: Scale to $100K ARR (Month 4–12)
- 8–10 Professional Assessments/quarter at $8K = $64–80K/year
- 3–5 Enterprise Retainers at $24K = $72–120K/year
- Total blended: $136–200K/year with 2 analysts

**Milestone targets:**
- Month 6: $50K cumulative revenue
- Month 12: $100K ARR
- Month 18: $250K ARR (with first platform license customer)
