The 40-point ShipPrompt audit.

This is exactly what we run against your repo. The full checklist with scoring is the audit deliverable.

Deployment automation

  1. Single-command deploy
  2. One-command rollback
  3. Idempotent infra-as-code
  4. Pinned model + framework versions
  5. Reproducible build from clean checkout

Prompt registry & versioning

  1. Prompts stored in Git, not Notion
  2. Stable prompt IDs & semantic versions
  3. Signed prompt artifacts
  4. Diff-able prompt history
  5. Prompt → model binding manifest

CI/CD & eval gates

  1. Eval suite runs on every PR
  2. Quality regression blocks merge
  3. Canary & staged rollout
  4. Auto-tagging of deploys
  5. Required reviewers for prompt PRs

Observability

  1. Per-prompt latency + cost metrics
  2. Per-model token attribution
  3. Trace IDs across model calls
  4. Prompt-version tag on every log line
  5. SLO + alerting wired

Security & secrets

  1. No keys in git history (gitleaks gate)
  2. Provider keys scoped + rotated
  3. Egress policy on inference workers
  4. Prompt-injection test corpus
  5. Output filtering / PII guard

Compliance & audit trail

  1. Model lineage record
  2. Prompt change attribution (who/when/why)
  3. Approval workflow for prod prompt changes
  4. Retention & deletion policy
  5. SOC 2 / EU AI Act evidence export

Cost controls

  1. Monthly inference budget & alerts
  2. Per-feature cost dashboard
  3. Caching layer for deterministic prompts
  4. Model-tier routing (cheap → premium)
  5. Idle worker shutdown

Reliability & runbook

  1. Documented rollback procedure
  2. On-call rotation
  3. Incident postmortem template
  4. Disaster recovery test in last 90 days
  5. Vendor-failover plan (OpenAI ↔ Anthropic ↔ self-host)
